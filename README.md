# Imitation Learning Project EE-568 (EPFL)

Applied Project 3 for the *Reinforcement Learning* course (EE-568) at EPFL.

## Project goal

The project compares several **Inverse Reinforcement Learning** algorithms on two classic continuous-control environments:

- **Pendulum-v1**
- **MountainCarContinuous-v0**

The pipeline is the following: an *expert* policy is first trained with **PPO** (Proximal Policy Optimization), demonstration trajectories are collected from it, and then we try to recover the expert's policy and reward function from demonstrations only, without access to the true environment reward. The algorithms we compare are:

- **IQ-Learn** Inverse soft-Q Learning.
- **f-IRL** Inverse RL based on f-divergence matching.
- **f-IRL + SOAR** variant with *State-Occupancy-Aware Regularization*.

The code also produces learning curves, learned-reward heatmaps and state-visitation plots, plus a small **gSDE ablation** for PPO on MountainCarContinuous.

## Difference between the files

- **`imitation_learning_project.ipynb`** the *reference* file of the project. It contains exactly the same code as the `.py` script, but organized in cells and **commented and argued** step by step: theoretical motivation of each algorithm, interpretation of the results. It is meant to be *read*.
- **`imitation_learning_project.py`** the *executable* version of the same code, extracted from the notebook. It runs everything end-to-end (expert training, demonstration collection, IQ-Learn / f-IRL / f-IRL+SOAR, generation of all the plots in `artifacts/results/`) without opening Jupyter. This is what you use to *run* the project.
- **`test_sde_mcc.py`** standalone script for the **gSDE** (generalized State-Dependent Exploration) ablation on PPO in MountainCarContinuous-v0. Trains two experts with and without `use_sde`, saves weights, records rollout videos and plots the training curves side by side in `artifacts/sde_ablation/`.

## Installing the dependencies

A virtual environment is recommended (conda or venv):

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## How to run

Full pipeline (expert training + IRL + plots):

```bash
python imitation_learning_project.py
```

gSDE ablation:

```bash
python test_sde_mcc.py
```

For the readable, commented version open the notebook instead:

```bash
jupyter notebook imitation_learning_project.ipynb
```

## Libraries used

- **[Gymnasium](https://gymnasium.farama.org/)** RL environments (`Pendulum-v1`, `MountainCarContinuous-v0`).
- **[Stable-Baselines3](https://stable-baselines3.readthedocs.io/)** PPO implementation used to train the experts.
- **[PyTorch](https://pytorch.org/)** backbone for all neural networks (policy, IQ-Learn Q-network, f-IRL discriminators).
- **NumPy**, **Matplotlib**, **Pandas**, **tqdm**, **rich**, **PyYAML** standard scientific stack for computation, plotting, logging and configuration.
- **Jupyter / ipykernel** for the notebook.
- **imageio** rollout video recording for the gSDE ablation.

Minimum versions are listed in [requirements.txt](requirements.txt).
